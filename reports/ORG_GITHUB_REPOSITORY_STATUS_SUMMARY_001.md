This report deliberately separates six evidence layers:

- `SOURCE`: source/material exists and, where stated, is released/merged.
- `VALIDATION`: deterministic or hosted validation evidence exists.
- `INTEGRATION`: downstream/upstream binding is evidenced rather than merely described.
- `RUNTIME`: the repository's intended runtime behavior has been observed.
- `EXTERNAL-PROVIDER`: an authentic provider/external-system operation has been observed when applicable.
- `PUBLIC-E2E`: a public end-to-end outcome has been observed when applicable.

Evidence values are conservative. `UNKNOWN` means this census did not locate enough current canonical evidence to promote the claim. `N/A` means that layer is not required for the repository role established by the cited handoff/status surface. A non-empty repository is never promoted above `SOURCE=PRESENT` merely because code exists.
