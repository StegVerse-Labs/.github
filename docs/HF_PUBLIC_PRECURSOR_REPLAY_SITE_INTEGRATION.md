Goal Task ID: `HF-PUBLIC-PRECURSOR-REPLAY-001`
COSV task.v1: `40000100100001`

This experiment is not a standalone public product. It is the historical-evidence and acceptance sub-lane of the existing StegVerse-Labs/Site Hugging Face living-analysis/public-display workstream governed by `docs/NVIDIA_HUGGING_FACE_ANALYSIS_MIRROR_HANDOFF.md` and Site issue #1079.

## Single public surface

The existing Site Hugging Face analysis remains the sole public display surface. Historical replay records that satisfy the acceptance contract are projected into that surface; the experiment must not create a second Hugging Face page, dashboard, monitor, or competing dataset.

## Acceptance boundary

A reconstructed event may enter the public historical timeline only when the evidence establishes what was publicly observable at the event's historical observer cutoff. Later disclosures may be attached as retrospective annotations but must not overwrite the contemporaneous observation, interpretation, attribution, or governance state. If contemporaneous public evidence cannot be recovered, the historical state remains `UNKNOWN` / `UNPROVEN_PENDING_ARTIFACT_RECOVERY`.

## Display fields

Accepted records preserve at minimum:
- event time
- observer cutoff time
- public observability at cutoff
- observation
- interpretation at cutoff
- attribution at cutoff
- governance state at cutoff
- later annotation and publication time
- source/provenance reference
- benign-alternative / false-positive analysis

## Prospective continuity

The same normalized separation applies to future live Hugging Face monitoring so historical replay and prospective observation use one evidentiary model. Public observation does not imply private telemetry access, attribution, compromise, or governance authority.
