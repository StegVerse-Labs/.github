## Abstract candidate (for both authors' substantive approval)

AI-governance systems act on machine-readable representations, yet the boundary between an observation and an interpretation can be obscured before a governance rule is applied. We investigate how missing input, explicitly bounded non-emission, and the temporal resolution of externally observed events affect the evidence available for governed decisions. A controlled SDK experiment contrasts missing input with a manifest-supplied non-emission observation under a fixed evaluator, showing that alternative representations can yield different governed dispositions. A subsequent cross-system study examines an API-based conversational trace and an independently constructed governance representation of sustained non-emission and return to speech. A provenance correction revealed that a statement describing model presence during an interval without an API request had been authored by the human experimenter, not produced by the model. Accordingly, the uninvoked interval establishes an interface-observability limit, not an inference about the model's internal state. In the controlled governance path, two explicitly supplied observation windows retain separate predecessor-dependent transitions and survive recorded custody, deterministic replay, and reconstruction. The experiments therefore identify distinct points at which measurement, attribution, and representation shape downstream governance evidence. We propose an independently attributable evaluation method that keeps native output, client-observed non-invocation, human annotation, optional interpretation, and governed state separate. A jointly designed invoked-HOLD follow-up remains prospective and is not included among the completed results.
